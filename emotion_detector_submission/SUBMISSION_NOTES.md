# Emotion Detector Submission Notes

This folder contains a clean reference implementation for the Coursera "Emotion Detector" final project.

## What to submit in the Coursera form

1. `README.md` URL
2. `emotion_detection.py` code or terminal output
3. `__init__.py` URL
4. `test_emotion_detection.py` code or terminal output
5. `server.py` code, screenshots, and pylint output

## URL fields

For questions that ask for a GitHub URL, replace the placeholders below with your own public repository links:

- `https://github.com/<your-username>/<your-repo>/blob/main/README.md`
- `https://github.com/<your-username>/<your-repo>/blob/main/EmotionDetection/__init__.py`
